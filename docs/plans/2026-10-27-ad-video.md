# Kế hoạch: Video quảng cáo AI nhiều cảnh (26.31.0, engine `ahv_ad`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Video Studio có engine thứ hai `ahv_ad`: MaiHub gửi kịch bản 2–10 cảnh sang API `ad_video` của AHV AI, theo dõi tiến độ theo bước, tải MP4 về kho video sẵn có, phát `videos.finished` kèm `warnings`. Bot gọi được bằng `videos.adCreate`; người dùng tạo được bằng form "Video quảng cáo AI".

**Architecture:** chỉ thêm vào khung Video Studio sẵn có, không dựng hệ thứ hai.
- `src/services/video/AhvAdClient.ts` — HTTP với `ai.ahvchat.com` (`/upload`, `POST /v1/jobs` task `ad_video`, `GET /v1/jobs/{id}`, `/v1/audio/voices`, tải MP4), ném `RenderError` như `RenderClient`.
- `src/services/video/ahvSettings.ts` — `app_settings.ahv_video_settings`, dùng lại `KeyCrypto` / `maskKey` của `videoSettings.ts`.
- `src/services/video/adVideoPayload.ts` — kiểm tham số và dựng payload AHV (thuần, không I/O).
- `VideoService` — `adCreate()` và nhánh `pollAd()` trong vòng poll duy nhất.
- `videoOperations` — `ahvSettingsGet/Set`, `ahvTestConnection`, `voices`, `adCreate`.
- Control API `videos.adCreate`; bridge `GUIDE`; UI `AdVideoForm` + `adVideoFormat.ts` + thẻ cài đặt.

**Tech Stack:** Electron 41, React 18, TypeScript, better-sqlite3, Jest (ts-jest), Python 3 cho bridge. Không thêm phụ thuộc mới (dùng `fetch`, `FormData`, `fs.openAsBlob` như `RenderClient`).

**Spec:** `docs/specs/2026-10-27-ad-video.md`. Hợp đồng API: mục 11 `docs-webhook.html` + `docs/ad_video_api.md` của AHV AI.

## Global Constraints

- **Chỉ thêm.** Không sửa hành vi engine `hyperframes`; không thêm mã lỗi Control API; không thêm bảng.
- **Định danh tiếng Anh**, chữ hiển thị / log / tài liệu tiếng Việt. Tên trường của AHV (`image_url`, `end_line`…) chỉ xuất hiện trong `AhvAdClient` và `adVideoPayload`.
- **Khoá API không bao giờ** vào log, `spec_json`, thông báo lỗi hay tin cho bot.
- **Hằng số dùng chung một chỗ** (`adVideoPayload.ts`): số cảnh 2–10, `prompt`/`setting` ≤ 500, `line`/`voiceover`/`endLine` ≤ 300, `motion` ≤ 120, `website` ≤ 100, `duration` 2,0–4,3, `speed` 0,7–1,3. UI và `videoOperations` cùng dùng, không chép số.
- **Không tự tính** tổng độ dài 10–60 s và độ dài lời đọc (để AHV trả `AD_TOTAL_DURATION` / `AD_LINE_TOO_LONG`).
- **Lệnh chạy:** `npx jest --runInBand <paths>`; `node --max-old-space-size=4096 node_modules/typescript/bin/tsc -p tsconfig.electron.json --noEmit` rồi `-p tsconfig.json`; `npm run build:electron`; `npm run build:renderer`; `node scripts/check-docs.js`; bridge: `cd tools/maihub-bridge && python3 -m unittest discover -s tests -q`.
- **Không được làm:** push GitHub; gọi job `ad_video` thật (tốn GPU) — chỉ ca lỗi rẻ; sửa hay khởi động lại máy chủ AHV; sửa worktree `ad-video`.
- **Git:** nhánh `feat/26.31-ad-video`, tác giả `MaiHub Bot`, commit kết thúc bằng dòng trống + `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

# Giao diện macOS (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đưa AHV Connect sang ngôn ngữ thiết kế macOS theo bộ "North": token màu dùng chung cho light/dark, khung app mới (sidebar 240 px thu gọn được, toolbar 52 px, nút cửa sổ theo hệ điều hành, vật liệu trong suốt thật khi hệ điều hành hỗ trợ), chế độ Sáng/Tối/Theo hệ thống, và toàn bộ màn hình hiện có đổi theo mà không phải sửa từng file.

**Architecture:** Token khai báo một lần bằng biến CSS trong `src/ui/index.css` (kênh RGB `--rgb-*` và màu đầy đủ). `tailwind.config.js` nối các sắc `gray-*` và `blue-*` mà code đang dùng vào token, **riêng cho từng loại utility** (`backgroundColor`, `textColor`, `borderColor`…), nên `bg-gray-700` và `border-gray-700` trỏ tới hai token khác nhau. 138 quy tắc ghi đè light cũ được gỡ bằng một script. Main process quyết định vật liệu và kiểu nút cửa sổ theo hệ điều hành (module thuần `electron/windowAppearance.ts`, có unit test) và báo cho renderer qua IPC. Khung app được dựng lại trong `Sidebar.tsx`, `SidebarAccounts.tsx` (mới) và `TopBar.tsx` (thành toolbar), giữ nguyên toàn bộ logic nghiệp vụ.

**Tech Stack:** Electron 41, React 18, Zustand 5, Tailwind CSS 3.4.19, PostCSS 8 (đã cài), jest 29 + ts-jest (`testEnvironment: node`).

## Review Focus

Năm chỗ dễ sai nhất. Mỗi chỗ có cách kiểm cụ thể.

1. **Quy tắc ghi đè light còn sót thắng token** (độ ưu tiên `html[data-theme="light"] .x` cao hơn `.x`). Kiểm: sau Task 1, `grep -nE 'data-theme="light"\] [^,{]*(bg|text|border|divide|ring|placeholder)-gray-[0-9]' src/ui/index.css` không in gì; ảnh chụp light toàn app (Task 7).
2. **Chữ không đủ tương phản** khi một token bị chỉnh tay. Kiểm: `src/__tests__/ui/themeTokens.test.ts` tính tương phản mọi cặp chữ/nền từ chính `index.css`.
3. **Nút X trên Windows/Linux phải ẩn app xuống khay, không thoát.** Nút gốc của hệ điều hành đi qua sự kiện `close` của `BrowserWindow`, đã có xử lý ẩn xuống khay tại `electron/main.ts` (`mainWindow.on('close', …)`). Kiểm tay ở Task 7: bấm X → app ẩn, icon khay còn, mở lại được.
4. **Mất vùng kéo cửa sổ hoặc nút bấm không nhận click** vì `-webkit-app-region: drag` phủ lên. Quy tắc CSS `.app-drag button, .app-drag .absolute, .app-drag [role="menu"], … { no-drag }` phủ mọi nút và mọi popup định vị tuyệt đối trong toolbar (dropdown workspace, popup kết nối lại, NotificationCenter, menu "Thêm", popover Giao diện). Kiểm tay ở Task 7: kéo cửa sổ bằng toolbar và đầu sidebar; mọi nút và popover trong toolbar bấm được.
5. **Chế độ "Theo hệ thống" không đổi theo hệ điều hành** vì `nativeTheme.themeSource` bị đặt cứng. Renderer gửi **preference** (không phải theme đã phân giải) cho main; main đặt `themeSource = preference`. Kiểm: unit test `theme.test.ts`, và kiểm tay đổi giao diện hệ điều hành khi app đang ở "Theo hệ thống" (Task 7).

## 1. Bối cảnh cho người chưa biết dự án

- AHV Connect là app Electron. Renderer là React (`src/ui/`), không có Node; gọi main qua `window.electronAPI.*` do `electron/preload.ts` công khai. Kiểu của `window.electronAPI` khai báo trong `src/ui/lib/ipc.ts` (`declare global`). Alias `@/` trỏ tới `src/ui/` (chỉ trong renderer; jest **không** hiểu alias này).
- State renderer dùng Zustand; `src/ui/store/appStore.ts` giữ `view` (màn hiện tại), `theme`, `fontSizeScale`, `sidebarExpanded`…
- Bố cục hiện tại (`src/ui/App.tsx` khoảng dòng 1417–1440): cột dọc gồm `<TopBar />` (36 px, toàn chiều ngang, là vùng kéo cửa sổ), `<EmployeeConnectionBanner />`, rồi hàng ngang `<Sidebar />` (thanh icon 64 px), `<AccountPanel />` (256 px, chỉ ở màn Chat khi mở rộng), nội dung.
- **Light mode hiện tại không dùng biến CSS.** Code viết cho nền tối (`bg-gray-900/800/700`, `text-gray-400`, `border-gray-700/600`…), và `src/ui/index.css` từ khoảng dòng 290 có 395 quy tắc `html[data-theme="light"] .<class> { … }` đổi từng class sang bảng màu kem. Kế hoạch thay cơ chế này bằng token.
- Theme gán ở `App.tsx`: `document.documentElement.dataset.theme = theme`. Cỡ chữ: `fontSizeScale` đổi `font-size` của `<html>` (16 px × hệ số).
- Cửa sổ chính tạo ở `electron/main.ts` hàm `createWindow()`: hiện `frame: isMac`, `titleBarStyle: hiddenInset` trên macOS, `backgroundColor: '#1a1a2e'`. Windows/Linux đang không có khung và TopBar tự vẽ nút thu nhỏ/phóng to/đóng (`TopBar.tsx` cuối file, khối `{!isMac && (…)}`).
- `ipcMain.on('window:close')` và sự kiện `close` của cửa sổ đều **ẩn app xuống khay** (không thoát) trừ khi `isQuitting`.
- CSP production chặn script nội tuyến (`script-src 'self'`), nên không chèn `<script>` vào `index.html`.
- **Spike đã chạy (02/10/2026, Linux GNOME Wayland, Electron 41.5.1):** cửa sổ `titleBarStyle: 'hidden'` + `titleBarOverlay: { color: '#00000000', symbolColor, height: 52 }` bật Window Controls Overlay (`navigator.windowControlsOverlay.visible === true`, vùng nút rộng 96 px × 52 px); `setTitleBarOverlay` gọi được. Chưa kiểm trên Windows và macOS (không có máy).
- Kết quả đo tương phản bộ token cuối cùng (nền xấu nhất): chữ phụ cấp 3 light 4,55:1, chữ xanh light 4,50:1, dark 4,63:1 và 4,70:1, chữ trắng trên nút xanh 4,70:1 (hover 5,32:1).

import * as fs from 'fs';
import * as path from 'path';

// Đọc token trực tiếp từ index.css để test đúng thứ đang chạy trong app.
const ROOT = path.resolve(__dirname, '../../..');
const css = fs.readFileSync(path.join(ROOT, 'src/ui/index.css'), 'utf8');
// eslint-disable-next-line @typescript-eslint/no-var-requires
const tailwindConfig = require(path.join(ROOT, 'tailwind.config.js'));

type Rgb = [number, number, number];

function block(selector: string): string {
  const start = css.indexOf(`${selector} {`);
  if (start < 0) throw new Error(`Không tìm thấy khối ${selector}`);
  return css.slice(start, css.indexOf('}', start));
}

function channels(source: string): Record<string, Rgb> {
  const out: Record<string, Rgb> = {};
  for (const m of source.matchAll(/--rgb-([a-z-]+):\s*(\d+)\s+(\d+)\s+(\d+);/g)) {
    out[m[1]] = [Number(m[2]), Number(m[3]), Number(m[4])];
  }
  return out;
}

const light = channels(block(':root'));
const dark = { ...light, ...channels(block('html[data-theme="dark"]')) };

function luminance([r, g, b]: Rgb): number {
  const f = (c: number) => {
    const s = c / 255;
    return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4;
  };
  return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b);
}

function contrast(a: Rgb, b: Rgb): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

const TEXT = ['text-primary', 'text-primary-soft', 'text-secondary-strong', 'text-secondary', 'text-tertiary', 'accent-text'];
const SURFACES = ['bg-deep', 'bg', 'bg-mid', 'surface', 'surface-mid', 'surface-raised', 'control', 'control-hover'];
const WHITE: Rgb = [255, 255, 255];

describe.each([['light', light], ['dark', dark]] as const)('%s theme tokens', (_name, t) => {
  it.each(TEXT.flatMap((text) => SURFACES.map((bg) => [text, bg])))('%s on %s reaches 4.5:1', (text, bg) => {
    expect(contrast(t[text], t[bg])).toBeGreaterThanOrEqual(4.5);
  });

  it.each([['text-primary'], ['text-secondary']])('%s on control-strong reaches 4.5:1', (text) => {
    expect(contrast(t[text], t['control-strong'])).toBeGreaterThanOrEqual(4.5);
  });

  it.each([['accent-fill'], ['accent-fill-hover'], ['accent-fill-pressed']])('white text on %s reaches 4.5:1', (fill) => {
    expect(contrast(WHITE, t[fill])).toBeGreaterThanOrEqual(4.5);
  });

  it('accent reaches 3:1 against every surface (non-text)', () => {
    for (const bg of SURFACES) expect(contrast(t.accent, t[bg])).toBeGreaterThanOrEqual(3);
  });
});

describe('tailwind token mapping', () => {
  const extend = tailwindConfig.theme.extend;
  const referenced = new Set<string>();
  for (const key of ['backgroundColor', 'textColor', 'borderColor', 'placeholderColor', 'ringColor']) {
    for (const shades of Object.values(extend[key] as Record<string, Record<string, string>>)) {
      for (const value of Object.values(shades)) {
        const m = /var\(--rgb-([a-z-]+)\)/.exec(value);
        if (m) referenced.add(m[1]);
      }
    }
  }

  it('references only tokens defined for both themes', () => {
    expect(referenced.size).toBeGreaterThan(10);
    for (const name of referenced) {
      expect(light[name]).toBeDefined();
      expect(dark[name]).toBeDefined();
    }
  });

  it('maps the same gray shade to different roles for background and border', () => {
    expect(extend.backgroundColor.gray['700']).toBe('rgb(var(--rgb-control) / <alpha-value>)');
    expect(extend.borderColor.gray['700']).toBe('rgb(var(--rgb-border) / <alpha-value>)');
    expect(extend.textColor.gray['400']).toBe('rgb(var(--rgb-text-secondary) / <alpha-value>)');
  });
});

describe('light overrides', () => {
  it('no longer override tokenised gray classes', () => {
    expect(css).not.toMatch(/html\[data-theme="light"\] [^,{]*\.(hover\\:)?(bg|text|border|divide|ring|placeholder)-gray-\d/);
  });
});

- [ ] **Step 5: Gỡ quy tắc ghi đè light bằng script**

Lưu script sau vào một thư mục tạm **ngoài repo** (ví dụ `/tmp/macos-ui/strip-light-overrides.js`), rồi chạy từ thư mục gốc repo: `node /tmp/macos-ui/strip-light-overrides.js src/ui/index.css`

```js
// Một lần: gỡ quy tắc ghi đè light mà token đã thay thế. Không commit script này.
// Chạy từ thư mục gốc repo: node <đường dẫn script> src/ui/index.css
const fs = require('fs');
const postcss = require(require.resolve('postcss', { paths: [process.cwd()] }));

const file = process.argv[2];
const root = postcss.parse(fs.readFileSync(file, 'utf8'));
const LIGHT = 'html[data-theme="light"]';
// Các utility đã nối vào token trong tailwind.config.js.
const TOKENIZED = [
  /(^|[^-])\b(bg|text|border|divide|ring|placeholder)-gray-\d{2,3}\b/,
  /\bbg-blue-(500|600|700)\b/,
  /\btext-blue-(300|400|500|600)\b/,
  /\bborder-blue-(400|500|600)\b/,
  /\bring-blue-(400|500|600)\b/,
];
// Quy tắc light được thay bằng token ở base/components.
const REPLACED = [
  /^html\[data-theme="light"\] body$/,
  /^html\[data-theme="light"\] ::-webkit-scrollbar-thumb(:hover)?$/,
  /^html\[data-theme="light"\] \.input-field/,
  /^html\[data-theme="light"\] \.task-editor-select/,
  /^html\[data-theme="light"\] \.btn-secondary/,
  /^html\[data-theme="light"\] \.(bg|border)-\\\[\\#1e2535\\\]$/,
];
let removedSelectors = 0;
let removedRules = 0;
root.walkRules((rule) => {
  if (!rule.selector.includes(LIGHT)) return;
  const keep = rule.selectors.filter((sel) => {
    if (REPLACED.some((re) => re.test(sel))) return false;
    // Ngoại lệ giữ chữ trắng trên nút màu: vẫn cần ở light.
    if (/text-white/.test(sel)) return true;
    return !TOKENIZED.some((re) => re.test(sel));
  });
  removedSelectors += rule.selectors.length - keep.length;
  if (keep.length === 0) {
    rule.remove();
    removedRules++;
  } else if (keep.length !== rule.selectors.length) {
    rule.selectors = keep;
  }
});
fs.writeFileSync(file, root.toString());
console.log(`removed ${removedRules} rules, ${removedSelectors} selectors`);
```

```ts
import type { BrowserWindowConstructorOptions, TitleBarOverlay } from 'electron';
// Nếu `TitleBarOverlay` không import được theo tên, dùng `Electron.TitleBarOverlay`.

export type WindowMaterial = 'vibrancy' | 'mica' | 'none';
export type WindowTheme = 'light' | 'dark';

export interface WindowAppearance {
  material: WindowMaterial;
  /** true: nút cửa sổ gốc qua titleBarOverlay; false trên Windows/Linux: nút tự vẽ trong toolbar. */
  nativeControls: boolean;
}

/** Cao bằng toolbar trong renderer (`--toolbar-height` trong src/ui/index.css). */
export const TOOLBAR_HEIGHT = 52;

/** Windows 11 22H2: bản đầu tiên `backgroundMaterial` của Electron có tác dụng. */
const WINDOWS_MICA_MIN_BUILD = 22621;

/**
 * Quyết định vật liệu và kiểu nút cửa sổ theo hệ điều hành.
 * Phương án dự phòng (docs/plans/2026-10-02-macos-ui.md Task 3): nếu overlay hoặc mica
 * hỏng trên máy thật, đổi giá trị trả về ở đây; không cần sửa chỗ khác.
 */
export function resolveWindowAppearance(platform: NodeJS.Platform, osRelease: string): WindowAppearance {
  if (platform === 'darwin') return { material: 'vibrancy', nativeControls: false };
  if (platform === 'win32') {
    const build = Number(osRelease.split('.')[2]) || 0;
    return { material: build >= WINDOWS_MICA_MIN_BUILD ? 'mica' : 'none', nativeControls: true };
  }
  return { material: 'none', nativeControls: true };
}

export function solidBackgroundFor(theme: WindowTheme): string {
  return theme === 'dark' ? '#151516' : '#f2f2f7';
}

export function titleBarOverlayFor(theme: WindowTheme): TitleBarOverlay {
  return { color: '#00000000', symbolColor: theme === 'dark' ? '#f5f5f7' : '#1d1d1f', height: TOOLBAR_HEIGHT };
}

export function windowChromeOptions(
  platform: NodeJS.Platform,
  appearance: WindowAppearance,
  theme: WindowTheme,
): BrowserWindowConstructorOptions {
  if (platform === 'darwin') {
    return {
      titleBarStyle: 'hiddenInset',
      // Căn giữa hàng đầu sidebar (52 px): đèn cao 12 px → y = 20.
      trafficLightPosition: { x: 20, y: 20 },
      vibrancy: 'sidebar',
      visualEffectState: 'followWindow',
      backgroundColor: '#00000000',
    };
  }
  if (!appearance.nativeControls) {
    return { frame: false, backgroundColor: solidBackgroundFor(theme) };
  }
  const options: BrowserWindowConstructorOptions = {
    titleBarStyle: 'hidden',
    titleBarOverlay: titleBarOverlayFor(theme),
    backgroundColor: appearance.material === 'mica' ? '#00000000' : solidBackgroundFor(theme),
  };
  if (appearance.material === 'mica') options.backgroundMaterial = 'mica';
  return options;
}
```

function useUnreadConversationCount(): (zaloId: string) => number {
  const contacts = useChatStore((s) => s.contacts);
  const others = useAppStore((s) => s.othersConversations);
  return (zaloId) => {
    const acctOthers = others[zaloId] || new Set<string>();
    return (contacts[zaloId] || []).reduce(
      (sum, c) => (acctOthers.has(c.contact_id) || !(c.unread_count > 0) ? sum : sum + 1),
      0,
    );
  };
}

function AccountAvatar({ account, size }: { account: AccountInfo; size: number }) {
  const fallbackClass = isFacebook(account.channel) ? 'bg-blue-800' : isTelegram(account.channel) ? 'bg-blue-500' : 'bg-blue-600';
  const iconSize = Math.round(size * 0.4);
  return (
    <span className="relative flex-shrink-0" style={{ width: size, height: size }}>
      <span className="block w-full h-full rounded-full overflow-hidden">
        {account.avatar_url ? (
          <img
            src={toLocalMediaUrl(account.avatar_url)}
            alt={account.full_name}
            className="w-full h-full object-cover"
            onError={(e) => {

                if (newUrl) {
                  useAccountStore.getState().updateAccount(account.zalo_id, { avatar_url: newUrl });
                  img.src = newUrl;
                  img.style.display = '';
                } else {
                  useAccountStore.getState().updateAccount(account.zalo_id, { avatar_url: '' });
                }
              }).catch(() => {
                useAccountStore.getState().updateAccount(account.zalo_id, { avatar_url: '' });
              });
            }}
          />
        ) : (
          <span className={`w-full h-full flex items-center justify-center text-white ${fallbackClass}`}>

          </span>

  );
}

/** Logo, tên app, phiên bản và nhãn cập nhật (chuyển từ TopBar). */
function SidebarBrand({ collapsed, macRail }: { collapsed: boolean; macRail: boolean }) {
  const { status: updateStatus, updateInfo, openUpdatePopup } = useUpdateStore();

```tsx
import React, { useEffect, useRef, useState } from 'react';
import { useAppStore } from '@/store/appStore';
import type { ThemePreference } from '@/lib/theme';

const OPTIONS: { value: ThemePreference; label: string; description: string }[] = [
  { value: 'light', label: 'Sáng', description: 'Luôn sáng' },
  { value: 'dark', label: 'Tối', description: 'Luôn tối' },
  { value: 'system', label: 'Theo hệ thống', description: 'Tự động' },
];

/** Nút ◐ trên toolbar: chọn Sáng / Tối / Theo hệ thống (spec mục 7.4). */
export default function AppearanceMenu() {
  const { themePreference, setThemePreference } = useAppStore();
  const [open, setOpen] = useState(false);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!open) return;
    const onDown = (e: MouseEvent) => { if (ref.current && !ref.current.contains(e.target as Node)) setOpen(false); };
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') setOpen(false); };
    document.addEventListener('mousedown', onDown);
    document.addEventListener('keydown', onKey);
    return () => {
      document.removeEventListener('mousedown', onDown);
      document.removeEventListener('keydown', onKey);
    };
  }, [open]);

  return (
    <div className="relative" ref={ref}>
      <button
        type="button"
        className="app-toolbar-btn"
        onClick={() => setOpen(v => !v)}
        title="Giao diện"
        aria-label="Giao diện"
        aria-haspopup="menu"
        aria-expanded={open}
      >
        <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="1.8">
          <circle cx="12" cy="12" r="9" /><path d="M12 3a9 9 0 0 1 0 18z" fill="currentColor" />
        </svg>
      </button>
      {open && (
        <div className="mac-popover absolute right-0 top-full mt-1.5 z-[9999]" role="menu" aria-label="Giao diện">
          <div className="mac-popover-title">Giao diện</div>
          {OPTIONS.map(option => (
            <button
              key={option.value}
              type="button"
              role="menuitemradio"
              aria-checked={themePreference === option.value}
              className="mac-menu-item"
              onClick={() => { setThemePreference(option.value); setOpen(false); }}
            >
              <span className="w-3.5 text-blue-500" aria-hidden="true">{themePreference === option.value ? '✓' : ''}</span>
              <span>{option.label}</span>
              <span className="ml-auto text-[11px] text-gray-500">{option.description}</span>
            </button>
          ))}
        </div>
      )}
    </div>
  );
}
```

Kiểm bằng cách thu cửa sổ xuống chiều cao tối thiểu (600 px): nhóm Tài khoản phải tự cuộn, nhóm Điều hướng và Cài đặt vẫn thấy đủ. Ô lọc kiểm bằng cách tạm đổi `FILTER_THRESHOLD` thành 1, rồi hoàn lại (không commit thay đổi tạm).
2. Trình duyệt với 1.000 profile (dùng vòng lặp `browserProfile.create` trong Console như kế hoạch Browser Profiles), cuộn danh sách: không giật so với trước (đo thời gian render < 1 s); xóa 1.000 profile sau đó.
3. Lặp lại ảnh chụp ở Step 2 cho Tổng quan, Chat, Trình duyệt sau khi đã có dữ liệu nặng, ở 1366×768 và 390×844, Sáng và Tối.

- [ ] **Step 5: Windows và macOS (chủ sản phẩm hoặc người có máy)**

Không có máy trong lúc viết kế hoạch. Gửi chủ sản phẩm danh sách kiểm:
- Windows 11: nền mica sau sidebar; nút cửa sổ gốc, snap layouts khi rê chuột vào nút phóng to; X ẩn xuống khay; đổi Sáng/Tối thì biểu tượng nút đổi màu.
- Windows 10: nền đặc (không mica); nút gốc như trên.
- macOS: traffic light nằm giữa hàng đầu sidebar; sidebar trong suốt thấy hình nền; thu gọn sidebar thì traffic light vẫn không đè avatar.

Nếu một mục hỏng: áp dụng "Phương án dự phòng" ở Task 3 Step 12, ghi vào mục "Kết quả kiểm chứng".

- [ ] **Step 6: Viết lại `DESIGN.md`**

Giữ phần logo hiện có (dấu hiệu, lý do, ràng buộc tỉ lệ, biến thể, sửa logo). Thay phần đầu và phần "Giao diện màn hình Trình duyệt" bằng hệ thống chung:
- YAML front matter: giữ `brand` và khối logo (`geometry`, `source`, `sizes`); thêm `color.light` và `color.dark` với **đúng** các giá trị `--rgb-*` và token rgba ở Task 1 (ghi dạng hex), `typography` (font, cỡ 13/12/10/21/28, đậm), `radius` (7/10/14/18), `elevation` (`shadow-card`, `shadow-popover`), `layout` (`sidebar-width: 240`, `rail-width: 64`, `rail-width-mac: 76`, `toolbar-height: 52`), `motion` (140/220/250 ms), `accessibility` (chữ 4,5:1, thành phần không phải chữ 3:1).
- Văn bản: định hướng North (nội dung trước chrome; light nền xám nhạt, dark nhiều cấp surface; vật liệu chỉ ở sidebar và chỉ khi hệ điều hành hỗ trợ), quy tắc "không viết mã màu hex trong component mới; thêm token", cách nối Tailwind (bảng mục 5.2 của spec), quy tắc tương phản và test giữ quy tắc đó, nút cửa sổ theo hệ điều hành.
- Câu mở đầu đổi thành: tài liệu là nguồn sự thật cho nhận diện **và** toàn bộ giao diện.

- [ ] **Step 7: Ghi kết quả và commit**

Thêm mục "Kết quả kiểm chứng" ở cuối kế hoạch: ngày, máy, kết quả từng bước Step 1–5, lỗi đã sửa (file, mô tả), mục chưa kiểm được và lý do.

```bash
git diff --stat 358c7c4
git add DESIGN.md docs/plans/2026-10-02-macos-ui.md
git commit -m "docs(ui): record macOS UI verification and design system"
```

Xác nhận `git diff --stat 358c7c4` chỉ chứa file có trong mục 2 (và file sửa lỗi đã ghi trong "Kết quả kiểm chứng"). Không `git push`.

## Rủi ro đã biết còn lại sau MVP

- Bố cục bên trong từng màn chưa theo macOS (đợt 2): Chat, CRM… chỉ đổi màu.
- Các bảng màu trạng thái (green, red, amber, purple…) và các quy tắc light cho chúng vẫn theo hệ cũ; một số sắc nền nhạt (`bg-white/*`, `bg-black/*` ở light) còn ánh kem.
- 48 màu hex trong `className` và khoảng 62 trong `style` chưa đi qua token.
- Mica, nút cửa sổ gốc trên Windows và vibrancy trên macOS chưa chạy thử trên máy thật lúc viết kế hoạch.
- Khi người dùng chọn theme khác hệ điều hành, lần mở app đầu tiên có thể chớp màu nền của hệ điều hành trong tích tắc trước khi renderer báo theme cho main.

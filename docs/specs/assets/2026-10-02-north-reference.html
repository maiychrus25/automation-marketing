Design system

Một hệ thống giao diện desktop lấy cảm hứng từ macOS, nhưng được thiết kế để hoạt động tự nhiên trên cả Windows và Linux.

Visual language

Giao diện ưu tiên hierarchy rõ ràng, typography sạch và khoảng trắng rộng. Sidebar, toolbar và content surface tạo thành một hệ thống phân cấp nhẹ thay vì dùng shadow mạnh.

Light mode sử dụng nền xám rất nhạt thay cho trắng tuyệt đối. Dark mode sử dụng nhiều cấp surface thay vì đơn giản đảo trắng thành đen.

✦
Design principle. Component không sử dụng màu hex trực tiếp. Mọi màu đều đi qua semantic token để Light và Dark có thể thay đổi độc lập.

Token architecture

UI được chia thành primitive tokens và semantic tokens. Điều này giúp thay đổi toàn bộ visual direction mà không cần sửa từng component.

--color-bg --color-surface --color-surface-hover --color-surface-selected --color-text-primary --color-text-secondary --color-text-tertiary --color-border --color-divider --color-accent --color-success --color-warning --color-danger

Platform behavior

Visual language có thể dùng chung, trong khi window chrome và system integration thích nghi theo từng OS. Windows giữ hành vi native của Windows; Linux tôn trọng window manager.
